# [PRD] 오늘의 선택 룰렛 토스 미니앱 (Pilot Project)

## 1. 개요
* **서비스명**: 오늘의 선택 룰렛
* **플랫폼**: 토스 앱인앱 (Apps in Toss)
* **목표**: 점심 메뉴, 회식 장소, 가벼운 내기 등 일상의 결정을 도와주는 가볍고 빠른 미니앱
* **검수 통과 목표**: 단순 명료한 기능과 오류 없는 모바일 웹뷰 경험으로 단번에 토스 심사 통과

---

## 2. 주요 기능 명세
1. **룰렛 아이템 관리**
   * 기본 프리셋 제공 (예: 점심 메뉴 추천 - 제육, 김치찌개, 돈까스, 샐러드 등)
   * 사용자 정의 항목 추가 및 삭제 (최대 12개)
2. **룰렛 회전 인터랙션**
   * 시작 버튼 클릭 시 부드러운 가속/감속 Canvas 또는 SVG 애니메이션
   * 당첨 항목 팝업 노출 및 진동 피드백 (Toss Bridge `hapticFeedback` 연동, 브라우저에서는 진동 API 또는 Mock)
3. **결과 공유 및 다시하기**
   * 결과 복사 또는 토스 공유 기능

---

## 3. 토스 앱인앱 기술 및 UI 규격
* **뷰포트/높이**: `100dvh` 적용 및 스크롤 바운스 방지
* **Safe Area Inset**:
  ```css
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
  ```
* **Toss Bridge Mocking**:
  * `window.TossBridge`가 없는 일반 브라우저 환경에서도 에러 없이 기본 동작하도록 폴백(Fallback) 구현
* **심사 금지 사항 필터링**:
  * 외부 결제 유도 없음
  * 불필요한 개인정보(이름, 전화번호 등) 수집 없음
  * 앱 밖으로 벗어나는 외부 하이퍼링크 없음
