# [PRD] 오늘의 선택 룰렛 토스 미니앱 (Pilot Project)

## 1. 개요
* **서비스명**: 오늘의 선택 룰렛
* **플랫폼**: 토스 앱인앱 (Apps in Toss)
* **목표**: 점심 메뉴, 회식 장소, 가벼운 내기 등 일상의 결정을 도와주는 가볍고 빠른 미니앱
* **검수 통과 목표**: 단순 명료한 기능과 오류 없는 모바일 웹뷰 경험으로 단번에 토스 심사 통과

---

## 2. 주요 기능 명세
1. **룰렛 아이템 관리**
   * 기본 프리셋 제공 (예: 점심 메뉴 추천 - 제육, 김치찌개, 돈까스, 샐러드 등)
   * 사용자 정의 항목 추가 및 삭제 (최대 12개)
2. **룰렛 회전 인터랙션**
   * 시작 버튼 클릭 시 부드러운 가속/감속 Canvas 또는 SVG 애니메이션
   * 당첨 항목 팝업 노출 및 진동 피드백 (Toss Bridge `hapticFeedback` 연동, 브라우저에서는 진동 API 또는 Mock)
3. **결과 공유 및 다시하기**
   * 결과 복사 또는 토스 공유 기능

---

## 3. 토스 앱인앱 기술 및 UI 규격
* **뷰포트/높이**: `100dvh` 적용 및 스크롤 바운스 방지
* **Safe Area Inset**:
  ```css
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
  ```
* **Toss Bridge Mocking**:
  * `window.TossBridge`가 없는 일반 브라우저 환경에서도 에러 없이 기본 동작하도록 폴백(Fallback) 구현
* **심사 금지 사항 필터링**:
  * 외부 결제 유도 없음
  * 불필요한 개인정보(이름, 전화번호 등) 수집 없음
  * 앱 밖으로 벗어나는 외부 하이퍼링크 없음

## 5. 파일럿 범위 확정: 점심 메뉴 선택 룰렛 (v1 추가 요구사항)
> 위 1~4절의 요구사항은 모두 유지한다. 본 절은 이번 파일럿 아이디어("점심 메뉴 선택 룰렛")에 맞춰 범위를 구체화하고 보완한다.

### 5.1 핵심 사용자 시나리오
1. 사용자가 미니앱에 진입하면 **점심 메뉴 기본 프리셋**이 채워진 룰렛이 바로 보인다 (첫 화면에서 추가 입력 없이 바로 돌릴 수 있음).
2. "돌리기" 버튼을 누르면 룰렛이 가속 → 감속하며 회전하고, 멈춘 위치의 메뉴가 결과 팝업(바텀시트/다이얼로그)으로 표시된다.
3. 결과 화면에서 **다시 돌리기**, **결과 복사**, **공유하기**를 할 수 있다.
4. 사용자는 메뉴 항목을 추가/삭제하거나 **기본값으로 초기화**할 수 있다.

### 5.2 기능 상세 (2절 보완)
* **기본 프리셋 (점심 메뉴)**: 제육볶음, 김치찌개, 돈까스, 샐러드, 짜장면, 국밥, 초밥, 햄버거 (8개)
* **항목 규칙**
  * 최소 2개, 최대 12개 (2개 미만이면 돌리기 버튼 비활성화 + 안내 문구)
  * 항목 이름은 앞뒤 공백 제거 후 1~20자, 빈 값/중복(대소문자·공백 무시) 추가 불가
  * 12개 도달 시 추가 입력 비활성화 + 안내 문구
  * 항목 목록은 `localStorage`에 저장되어 재진입 시 복원 (저장 실패/손상 데이터 시 기본 프리셋으로 폴백). 서버 전송 없음
* **회전 로직**
  * 당첨 항목은 회전 시작 시점에 **균등 확률**로 먼저 결정하고, 애니메이션은 해당 섹터 중앙(±섹터 내 랜덤 오프셋)에 멈추도록 최종 각도를 계산한다 (결과와 화면 표시 불일치 금지)
  * 회전 시간 약 3~4초, ease-out 감속, 최소 4바퀴 이상
  * 회전 중에는 돌리기 버튼·항목 편집 비활성화 (중복 실행 방지)
  * `prefers-reduced-motion` 사용자에게는 회전 시간을 단축하거나 애니메이션 최소화
* **결과 피드백**: 당첨 시 햅틱 피드백 1회. 토스 환경이 아니면 `navigator.vibrate` 지원 시 사용, 미지원 시 무시(no-op)
* **결과 공유/복사**
  * 복사 문구 예: `오늘 점심은 "김치찌개"! 🍽️ - 오늘의 선택 룰렛`
  * 토스 환경: 앱인토스 SDK의 공유/클립보드 API 사용. 일반 브라우저: Web Share API → Clipboard API 순으로 폴백, 모두 실패 시 에러 없이 안내 토스트
  * 공유 문구에 외부 URL을 넣지 않는다 (3절 "외부 하이퍼링크 없음" 준수)

### 5.3 앱인토스 플랫폼 연동 (3절 보완 — 현행 공식 문서 기준)
> 3절의 `window.TossBridge` / `hapticFeedback` 표기는 개념상 요구사항으로 유지하되, 실제 구현은 현행 앱인토스 WebView SDK를 사용하고 **브리지 어댑터 모듈(`src/platform/`)** 뒤로 감싼다. 어댑터는 SDK 호출 실패·미지원 환경에서 예외를 던지지 않고 폴백한다.
* **프레임워크**: 앱인토스 WebView 미니앱 — `@apps-in-toss/web-framework` + `granite.config.ts` (`appName`, `brand.displayName`, `brand.primaryColor`, `brand.icon`, `web.host/port/commands`) 구성
* **SDK 매핑 (어댑터 인터페이스)**
  * `haptic(type)` → SDK `generateHapticFeedback({ type })` / 폴백 `navigator.vibrate` / no-op
  * `share(message)` → SDK `share({ message })` / 폴백 Web Share API → 복사
  * `copy(text)` → SDK 클립보드 API(`setClipboardText`) / 폴백 `navigator.clipboard.writeText`
  * 환경 감지 실패 시 "브라우저 모드"로 동작
* **UI**: 토스 디자인 시스템(TDS, WebView용 `@toss/tds-mobile`) 사용을 우선 검토. 상단 내비게이션 바는 플랫폼 제공 바를 사용하고 앱 내부에 중복 헤더/뒤로가기를 만들지 않는다
* **권한**: 결과 복사용 클립보드 쓰기 권한만 선언 (`permissions: [{ name: 'clipboard', access: 'write' }]`). 카메라·위치·연락처 등 그 외 권한 요청 없음
* **로컬 확인**: `npm run dev`(브라우저) 및 앱인토스 샌드박스 앱으로 확인. **배포/업로드(`ait deploy` 등)는 이번 범위에서 수행하지 않는다**
* ⚠️ 위 API 이름은 작성 시점에 공식 문서(https://developers-apps-in-toss.toss.im)를 온라인으로 재확인하지 못했다. 구현 착수 시 설치된 SDK 버전의 타입 정의/공식 문서와 대조하여 차이가 있으면 어댑터만 수정한다.

### 5.4 화면 구성
* **메인**: 룰렛(SVG, 섹터별 색상 + 상단 포인터) / 돌리기 버튼 / 항목 편집 영역(입력창 + 추가 버튼, 항목 리스트 + 삭제, 기본값 초기화)
* **결과 팝업**: 당첨 메뉴, 다시 돌리기, 결과 복사, 공유하기, 닫기
* **약관 페이지**: `/privacy`(개인정보처리방침), `/terms`(이용약관) — 앱 내부 라우트, 외부 링크 아님. 수집 개인정보 없음, 데이터는 기기 내 저장만 함을 명시
* **접근성**: 버튼 최소 터치 영역 44px, 결과는 `aria-live`로 낭독, 색상만으로 정보 전달하지 않음(섹터에 텍스트 표시)

### 5.5 비기능 요구사항
* 오프라인/네트워크 없이 동작 (외부 API 호출 없음)
* 콘솔 에러 0건 (브라우저 모드 포함)
* 360×640 ~ 430×932 화면에서 가로 스크롤 없음, 룰렛 텍스트 잘림 시 말줄임 처리
* 초기 번들 경량화 (불필요한 대형 라이브러리 미사용)

### 5.6 테스트 요구사항
* 단위 테스트 (Vitest): 항목 검증(빈값/중복/길이/최대 12개), 저장·복원·손상 데이터 폴백, 당첨 인덱스 ↔ 최종 각도 계산 일치, 균등 분포(대량 샘플 통계 검증, 시드 가능한 RNG 주입), 공유 문구 생성
* 플랫폼 어댑터 테스트: SDK 존재/부재/예외 시 각각 폴백 경로가 예외 없이 동작
* 컴포넌트 테스트 (React Testing Library): 항목 추가/삭제/초기화, 2개 미만 시 버튼 비활성화, 회전 중 중복 클릭 무시, 결과 팝업 표시(타이머 모킹), 약관 라우트 렌더
* 심사 금지사항 정적 검사 테스트: `src/`에 외부 `http(s)://` 링크·결제 관련 문구·개인정보 입력 필드가 없음을 확인
* `npm run test`, `npm run lint`, `npm run build` 모두 통과

### 5.7 범위 제외 (v1)
* 로그인/토스 계정 연동, 서버 저장, 결과 히스토리 동기화
* 광고, 인앱 결제, 프로모션
* 다국어 (한국어만)
* 실제 배포·심사 제출 (체크리스트 준비까지만)
